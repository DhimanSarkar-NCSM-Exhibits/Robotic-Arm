⚠️

Cannot run directly from the filesystem

This interface requires the Flask backend to function.

You opened index.html directly in your browser. The serial port controls and all backend features will not work this way. You must serve it through the Python script.

How to run

  1. 1Install dependencies if needed:
    pip install flask pyserial
  2. 2Open a terminal in the folder containing app.py and index.html.
  3. 3Run:
    python app.py
  4. 4Open one of the URLs below in your browser.

Then open in your browser

http://127.0.0.1:5000 http://localhost:5000

Requirements

pip install flask
pip install pyserial
